# Plett Driver Learning — demo

Interactive demonstration of a driver learning portal for R R Plett Trucking.

## Try it

Open the repository's GitHub Pages website. Choose **Continue learning** to try a course, or switch the header dropdown to **Safety admin** to explore sample assignments and reporting.

Includes five sample courses, lesson progression, a quiz and acknowledgement, local progress, sample training records, and CSV exports.

## Demo only

All learner identities, deadlines, assignments, and records are fictional. Lessons are illustrative placeholders, not approved operating instruction or proof of qualification. Progress is stored in this browser only. The role switch is a demonstration, not real authentication.

## Hosting

This package is self-contained: publish the main branch from / (root) in Settings → Pages. No build tools, dependencies, company accounts, or ChatGPT sign-in are needed to view a public GitHub Pages deployment.

The supplied company imagery is included for this project demonstration. No license is granted to third parties.
